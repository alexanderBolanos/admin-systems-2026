# admin-systems-2026

Proyecto de pruebas del curso Administracion de Sistemas.

## API de prueba

Este proyecto expone un endpoint en Express para validar una integración con GitHub Actions.

### Endpoint

- GET /hola-mundo
- Respuesta: Hola Mundo

### Ejecutar localmente

```bash
npm install
npm start
```

Luego puedes probarlo con:

```bash
curl http://localhost:3000/hola-mundo
```

### Validar con tests

```bash
npm test
```
